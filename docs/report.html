Risk notes

  • Executor. Every pool above is owner-only: the contract pays msg.sender. No company, relayer or agent can collect on the holder's behalf, and any offer to do so is false.
  • Lost keys. If the key to this address is gone, the balance is permanently unrecoverable. Chain state cannot distinguish a lost key from dormancy.
  • Admin-controlled pools. 0x4d55f76e… exposes an admin-only payout redirect (0x3fb9950a). The user's own call succeeds, but an operator can route the payout. Treat that pool as admin-controlled, not abandoned.
  • Gas. A claim worth less than its transaction is a loss. Net figures above use the live base fee.

Method

Each balance is the contract's own answer to balanceOf for this address. Each claim path was established by extracting PUSH4 selectors from the deployed runtime bytecode and then executing the withdrawal in an eth_call from this address; a pool is only reported when that call succeeds. Gas is the node's own estimate. No wallet connection, no signature, no key material is used at any point in producing this report.

About this research

This report is generated from public chain state and costs nothing to reproduce. It is the output of a verification pass over 158 ETH-denominated pools: which getters answer truthfully, which index entries are mis-scaled (one by 141x), which contracts have an admin who can redirect a payout, and which claim calls actually execute from a holder address.

No fee is charged for this report, no wallet is connected, and no key material is ever requested. Where a balance is worth less than its transaction, the report says so rather than encouraging it.
