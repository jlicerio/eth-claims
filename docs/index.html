Abandoned contract claims

An index of Ethereum contracts that still hold user funds, with the difference that matters: claim simulated means the withdrawal was executed in an eth_call from a real holder address and succeeded — not that a selector was merely found in a bytecode dump. An index tells you where to look; only a simulated claim from the holder's address tells you whether it is collectable.

Method: denomination check · PUSH4 selector provenance from runtime bytecode · getter read for a specific address · eth_call the claim from that address · executor class (owner-only vs third-party). Source and evidence: github.com/jlicerio/eth-claims. Categories. claim simulated = the withdrawal executed in an eth_call from a real holder and the getter is the payout. callable · token-priced = a claim call succeeds, but the getter returns tokens, so the amount is not ETH until the pool's price function is read. no verified shape = none of the probed getter/claim pairs matched. That means not examined successfully, not disproven. One pool is genuinely disproven: LastWinner, whose getter returns zero for the holder its index lists at 163.42 ETH. Token-denominated files are excluded from the ETH total by design.
